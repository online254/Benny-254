Help & Support

How M-Pesa payments work

Steps

1. Choose package.
2. Enter Safaricom number.
3. Request STK.
4. Enter PIN on phone.
5. Wait for verification.

Important

Never share M-Pesa PIN. Only approve prompt you requested. Save M-Pesa confirmation SMS. If deducted but not reflected, contact support with Transaction ID.
