6 skill paths
✳

Graphic Design

Learn visual communication, layouts, colour and brand consistency.

Start with: colour theory, typography, spacing and visual hierarchy. Practice by creating a simple poster, social media graphic and brand concept. Build a portfolio using original work.
⌨

Data & Transcription

Develop accuracy, document formatting and information-handling skills.

Start with: keyboard shortcuts, document formatting, spreadsheets and careful proofreading. Practice typing short sample audio transcripts and organising fictional spreadsheet records. Protect private data.
⌘

Web & Technology

Understand websites, coding basics and digital problem-solving.

Start with: HTML for structure, CSS for design and JavaScript for interaction. Build a personal profile page, make it mobile-friendly and learn to test changes before publishing.
✎

Writing & Communication

Practice clear writing, editing, research and professional messaging.

Start with: grammar, outlining, paragraph structure, editing and fact-checking. Write a short article, revise it for clarity and cite trustworthy sources when making factual claims.
◎

Social Media & Content

Learn content planning, audience awareness and responsible publishing.

Start with: audience research, content calendars, accessible design and simple performance metrics. Create a sample weekly content plan. Avoid spam, misleading claims and unauthorised use of other people's content.
↗

Online Business Basics

Understand digital services, client communication and project planning.

Start with: identifying a useful service, understanding client needs, writing clear proposals, agreeing on scope and tracking expenses. Learn to recognise suspicious offers and never promise guaranteed returns.
